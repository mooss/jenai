#+title: jenai

CLI that builds a text prompt from args, stdin, clipboard, and files/dirs/URLs, then sends it to a model via OpenRouter.
Also acts as a prompt manager of sorts, embedding a few useful prompts that can be quickly invoked by name.

* Examples

Review the staged changes with Sol:
#+begin_src bash :eval never
jenai p review_staged --model sol
#+end_src

Edit a file following pre-written guidelines:
#+begin_src bash :eval never
jenai edit Fix to fit the guidelines --read guidelines.md --write main.py
#+end_src

Query info from documentation in clipboard and hide reasoning:
#+begin_src bash :eval never
jenai o 'What exactly is a pipeline in this context?' --paste --thoughtless
#+end_src

Generate the description of this repo:
#+begin_src bash :results raw :exports both :wrap example :eval never
jenai o Create a short one line description of this project for GitHub --read go/cmd/jenai/main.go --thoughtless
#+end_src

* Build and requirements

Requires Go to be setup locally and install with =go install=:
#+begin_src sh
make install
#+end_src


* Commands

 - =oneshot|o= :: Create an ad-hoc prompt from positional arguments
 - =prompt|p= :: Use a prompt from the prompt library
 - =edit= :: Edit files according to instructions
 - =model-zoo|mz= :: Show configured model shortcuts
   - =details= :: Print details for a model, or the whole model zoo
   - =regen= :: Overwrites the given model zoo YAML with current OpenRouter info
 - =capa= :: List a model's OpenRouter capabilities
 - =prompt-library|pl= :: List the content of the prompt library


* Quick tour

** Config

API keys are stored in =/.config/jenai/config.yaml=.
First run explains how to set it up.

** Prompts

Prompts are Go templates written with primitives like =git=, =join=, =strings=, =ins=, =per=, =sec1= and access to positional args.
=prompt-library|pl= lists the names of the prompts embedded into =jenai=.

** Inputs

Prompt text is positional args + piped stdin + clipboard (=--paste=).
=oneshot|o [TEXT]= sends text as-is.
=prompt|p NAME [ARGS]= expands a library template.

** Arguments

The completion commands (=oneshot=, =prompt= and =edit=) use common flags to configure context, model selection and output.

*** Context

 - =--read= :: adds files.
 - =--read-dir= :: adds directories.
 - =--linum= :: includes line numbers.
 - =--paste= :: adds content of clipboard.

*** Model selection

 - =-m|--model= :: selects short zoo name (=glm-flash=) or =provider:author/model= (=openrouter:z-ai/glm-5.3-flash=).
 - =--effort= :: sets reasoning effort.

*** Output

 - =--copy= :: copies the output to the clipboard.
 - =-n|--dry-run= :: prints built prompt without calling the LLM.
 - =--tee= and =--thoughtless-tee|--tt= :: tees the output to the given file.
 - =-t|--thoughtless= :: hides thinking.
